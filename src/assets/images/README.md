# Images

Optional. Drop these in and they'll show up automatically; leave them out and nothing breaks.

| File             | Where it shows                                  | Suggested size        |
|------------------|-------------------------------------------------|-----------------------|
| `logo.png`       | above the title on the setup screen             | ~320×240, transparent |
| `background.jpg` | full-page background (replaces the gradient)    | 1920×1080, darkish    |

Paths are set in `js/config.js`. Colours are tokens at the top of `css/style.css`.
